# Contributing

Thank you for improving Open Review Assistant.

1. Open an issue describing the behavior or proposed change.
2. Keep changes focused and add tests for observable behavior.
3. Run `PYTHONPATH=src python3 -m unittest discover -s tests -v`.
4. Never commit real learner records, copyrighted question banks, database
   files, credentials, or machine-specific paths.
5. Use synthetic fixtures that can be freely redistributed.

By contributing, you agree that your contribution is licensed under the MIT
License included in this repository.
